# Periodic Table

A static, framework-free interactive periodic table for GitHub Pages.

## Tech
- Vanilla HTML/CSS/JS (ES Modules not required)
- Data: Bowserinator/Periodic-Table-JSON embedded locally

## Features
- 18xN grid layout via xpos/ypos
- Hover/focus tooltip with summary and uses
- Dialog with key properties and Wikipedia link
- Search by number/symbol/name
- Filters: category, phase, block
- Heatmap mini-bar per cell
- Random pick from current results
- Fun mode micro-interaction
- Keyboard navigation (arrows, Enter, Esc)
- Responsive (mobile horizontal scroll), long press tooltip
- Dark/Light toggle (default dark)
- Legend chips (click to filter)
- Accessibility and performance minded

## Run locally
Open `index.html` in a modern browser.

## Deploy
Push this folder to a GitHub Pages repository root (or docs/) and enable Pages.
